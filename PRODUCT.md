# EZTV reseller dashboard

The dashboard helps resellers manage prospects, customer accounts and follow-ups. Reseller websites are an extension of the existing Sales tools workspace.

## Reseller website scope — October 12, 2026

The owner requested an expanded, editable landing-page template with simple inquiries only. Every new inquiry must reach the reseller’s CRM (Sales tools → Leads & trials) and email. Automated account creation, trials, checkout and payments remain outside this website flow.

Each reseller controls the brand, logo, introduction, optional service/device content, FAQs and public contact email. Website pages remain private until an owned domain is verified and the reseller explicitly publishes. There is no shared-domain publishing fallback. Private setup instructions remain outside the public page.

Inquiries belong only to the reseller behind the connected hostname. Repeated messages from the same prospect remain visible with the existing lead. Email alerts go to the verified reseller login email; the public customer contact email remains separate. Delivery status must distinguish provider acceptance from confirmed inbox delivery and retain CRM access if sending fails. Email replies are not automatically imported into CRM conversations.

## Existing design constraint

This task extends the current page and editor. Preserve the established light background, dark text, reseller accent color, system typography, responsive form, logo treatment and explicit preview/publication controls. No new visual identity or commercial claims are authorized.
